# TG_VK_MAX_bot — погодный бот

Бот на Python помогает узнать погоду без отдельного приложения. **Сейчас реализована версия для VK**; Telegram и MAX — направления будущего развития, их интеграций в текущем коде нет.

**Попробовать:** [Погода в городе — бот](https://vk.ru/club241444817).

## Возможности

1. **Погода сейчас** — температура, ощущаемая температура и состояние погоды по названию города.
2. **Прогноз** — погода на ближайшие пять дней.
3. **Подробности** — ветер, влажность и другие доступные показатели.
4. **Геолокация** — погода для отправленной пользователем точки.
5. **Сравнение** — сопоставление погоды в двух городах.
6. **Мой город** — сохранение основного города для быстрых запросов.
7. **Обратная связь** — сохранение обращения и уведомление администратора.

## Как работает

Сообщения приходят через VK Bots Long Poll API. Обработчик выбирает действие, клиент OpenWeather запрашивает погодные данные по HTTPS, а бот возвращает ответ с кнопками. SQLite хранит настройки пользователей, историю и обращения. Транспорт, погодный API, бизнес-логика и хранилище разделены по модулям.

## Запуск

Нужны Python 3.10+ и зависимости `vk-api`, `requests`, `python-dotenv`. SQLite входит в Python.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python main.py
```

До запуска заполните `.env`: токен и ID сообщества VK, ключ OpenWeather. В сообществе включите сообщения, Bots Long Poll и событие «Входящее сообщение». Для уведомлений задайте `VK_FEEDBACK_PEER_ID`; получатель должен разрешить сообщения от сообщества. База создаётся автоматически, токены и данные пользователей в Git не добавляются.
