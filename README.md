# Weather Bot

VK-бот на Python показывает текущую погоду, прогноз на 5 дней, расширенные
показатели, погоду по геолокации и сравнение городов. Основной город, история
диалогов, обращения пользователей и логи сохраняются в локальной SQLite-базе.

## Запуск

1. В сообществе VK включите **Сообщения** и **Bots Long Poll API**, затем
   разрешите событие **Входящее сообщение**.
2. Скопируйте `.env.example` в `.env` и заполните ключи.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите бота: `python main.py`.

Файл `data/weather_bot.sqlite3` и таблицы создаются автоматически при первом
запуске. SQLite уже встроен в Python: отдельный сервер, пользователь и пароль
не нужны. Проверка проекта:
`python -m unittest discover -s tests -v`.

## Обратная связь

Укажите в `VK_FEEDBACK_PEER_ID` числовой ID или короткий адрес своего аккаунта,
например `paha_kenai`. С этого аккаунта нужно хотя бы один раз написать
сообществу и разрешить сообщения — после этого бот сможет присылать туда
обращения. Для нескольких администраторов можно указать числовой `peer_id`
беседы, в которую добавлено сообщество-бот.

Даже если уведомление VK временно не доставлено, обращение остаётся в таблице
`feedback`. Отдельное сообщество для обратной связи не требуется.

## Структура

- `weather_bot/openweather.py` — клиент OpenWeather;
- `weather_bot/handlers.py` — диалоги и форма обратной связи;
- `weather_bot/keyboards.py` — клавиатуры VK;
- `weather_bot/database.py` — SQLite, история диалогов и логи;
- `weather_bot/formatters.py` — оформление погодных сообщений.
